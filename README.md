## 💼 Professional Summary

I am a Full Stack Software Engineer specializing in the MERN Stack and Application Security (AppSec). I bridge the gap between high-performance web development and robust security architecture. By integrating security early into the Software Development Life Cycle (SDLC), I ensure that applications are highly scalable, user-centric, and inherently secure against modern threat vectors.

### Core Competencies

- **Application Security:** Auditing and hardening applications against OWASP Top 10 vulnerabilities (including XSS, SQLi, CSRF, and SSRF).
- **System Architecture:** Designing maintainable microservices and RESTful APIs, supported by responsive and accessible frontends.
- **Automation & Scripting:** Leveraging Python and Bash for security tooling, workflow automation, and infrastructure diagnostics.
- **Specialized Interests:** React optimization, secure authentication (JWT/OAuth), penetration testing, and secure-by-design architectures.
